Данный шаг общего процесса закупки начинается с физического поступления ТМЦ на склад Компании.

1. Кладовщик выполняет физическое поступление и пересчёт ТМЦ построчно

2. Кладовщик выполняет вход в Систему

3. Кладовщик открывает документ Goods Receipt PO. Система откроет форму документа в режиме добавления новой записи. 

4. Кладовщик заполняет документ следующим образом:

   ![image.png](/.attachments/image-eecac87c-c1d1-4baa-8fe4-1587769d21a3.png)
  
   (1) Вввести \ Выбрать из списка Поставщика
   (2) Ввести дату поступления (отражение фактической даты поступления). Все три даты должны быть равны
   (3) Ввести номер накладной Поставщика (номер на который в последствии можно ссылаться при общении с  
       Поставщиком)
   (4) Нажать кнопку [Copy From]

5. Система откроет список документов **открытых** Purchase Order, которые созданы для указанного Поставщика

![image.png](/.attachments/image-6ebc3d49-4b03-44af-b3fa-9ba384f4a3db.png)

В данном списке выбрать необходимый Заказ. И затем нажать кнопку [Choose]
(При необходимости есть возможность выбрать несколько Заказов. Для этого необходимо держать нажатыми клавиши клавиатуры [Shift] + [Ctrl])
 
6. Система откроет форму выбора данных для копирования из Заказа в Goods Receipt PO
![image.png](/.attachments/image-49dfc9e8-1c8c-46de-b3eb-3f4c2f6a953d.png)

7. В открывшейся форме необходимо выбрать
  'Use Current Exchange Rate from The Exchange Rate Table' - использовать текущий курс валюты для проводки документа
    
    'Customize' - предоставить пользователю возможность указать фактически полученное количество ТМЦ.
8. Система откроет окно для заполнения. 
Все строки окна выделены синим - это означает, что все эти строки будут скопированы в целевой документ. Если ТМЦ по какой-то строке не поступили в полном объёме, то необходимо сбросить выделение и выбрать строки для копирования (клик левой кнопки мыши) при нажатом [Ctrl]
![image.png](/.attachments/image-84ea8403-469f-414d-84ce-77f3d57ecb2b.png)
 
9. Кладовщик вносит фактические данные пересчёта для поступивших ТМЦ в колонку 'Qty', при этом обязательно сверяя значение в колонке 'UoM Code'. Также необходимо проверить (2) значения в колонке 'Whse' - должен быть установлен General Warehouse, и что все строки в колонках Key и Department заполнены. По окончания проверки нажать кнопку [Finish]

8. Система скопирует выбранные строки с указанными данными из Заказа (Заказов) в форму Goods Receipt PO
![image.png](/.attachments/image-9e905815-280e-426e-8b05-7de501e8bfd0.png)
Если все данные ранее были проверены, то для проводкм документа необходимо нажать кнопку [Add&View]
9. Система выполнит проводку документа. 
 В этот момент: 
ТМЦ будут добавлены на склад.
Будет создана бухгалтерская проводка  ДБ Inventory On Stock \ КТ Goods Received Not Invoiced  

10. Кладовщик нажимает кнопку [Print] расположенную на Панели инструментов и распечатывает документ подтвержения прихода для Поставщика. Или нажмает кнопку Preview и сохраняет форму как pdf файл
![image.png](/.attachments/image-3bf2f9fb-4ae0-4d44-b750-7c5c1bef8511.png)
