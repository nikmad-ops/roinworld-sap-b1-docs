Данный шаг общего процесса закупки начинается с физического поступления ТМЦ на склад Компании.  
Внимание: Сохранение документа Поступление формирует проводку ТМЦ на склад Компании. Также, при добавлении документа формируется бухгалтерская проводка. Это означает, что внесение изменений в проведённый документ становится невозможным. Изменение данных в документе возможно только путём создания документа Возврат (или Отмена Поступления)

Кладовщик выполняет физическое поступление и пересчёт ТМЦ построчно. Для отражения поступления необходимо выполнить следующие шаги:

1. Открыть документ Поступление\Goods Receipt PO. Система откроет форму документа в режиме добавления новой записи. Для этого из Главного меню-> Закупки -> Поступление

4. Заполнить Документ следующим образом:

   <img src="/.attachments/image-eecac87c-c1d1-4baa-8fe4-1587769d21a3.png" alt="image.png" width="100%" />

  
   (1) Вввести \ Выбрать из списка Поставщика  
   (2) Ввести дату поступления (отражение фактической даты поступления). Все три даты должны быть равны  
   (3) Ввести номер накладной Поставщика (номер на который в последствии можно ссылаться при общении с  
       Поставщиком)  
   (4) Нажать кнопку [Copy From]

5. Система откроет список документов **открытых** Purchase Order, которые созданы для указанного Поставщика

<img src="/.attachments/image-6ebc3d49-4b03-44af-b3fa-9ba384f4a3db.png" alt="image.png" width="100%" />


В данном списке выбрать необходимый Заказ. И затем нажать кнопку [Choose]  
(При необходимости есть возможность выбрать несколько Заказов. Для этого необходимо держать нажатыми клавиши клавиатуры [Shift] + [Ctrl])
 
6. Система откроет форму выбора данных для копирования из Заказа в Goods Receipt PO

<img src="/.attachments/image-49dfc9e8-1c8c-46de-b3eb-3f4c2f6a953d.png" alt="image.png" width="100%" />


7. В открывшейся форме необходимо выбрать
  'Use Current Exchange Rate from The Exchange Rate Table' \ 'Использовать текущий курс валюты для проводки документа'
    
    Выбрать 'Выбрать'\'Customize' - предоставить пользователю возможность указать фактически полученное количество ТМЦ.
8. Система откроет окно для заполнения. 
Все строки окна выделены синим - это означает, что все эти строки будут скопированы в целевой документ. Если ТМЦ по какой-то строке не поступили в полном объёме, то необходимо сбросить выделение и выбрать строки для копирования (клик левой кнопки мыши) при нажатом [Ctrl]

<img src="/.attachments/image-84ea8403-469f-414d-84ce-77f3d57ecb2b.png" alt="image.png" width="100%" />

 
9. Внести фактические данные пересчёта поступивших ТМЦ в колонку 'Количество'\'Qty', при этом обязательно сверить Единицы измерения \ 'UoM Code'. Также необходимо проверить (2) значения в колонке 'Whse' - должен быть установлен General Warehouse, и что все строки в колонках Key и Department заполнены. По окончания проверки нажать кнопку [Finish]

8. Система скопирует выбранные строки с указанными данными из Заказа (Заказов) в форму Goods Receipt PO

<img src="/.attachments/image-9e905815-280e-426e-8b05-7de501e8bfd0.png" alt="image.png" width="100%" />

Если все данные ранее были проверены, то для проводкм документа необходимо нажать кнопку [Добавить]\[Add&View]
9. Система выполнит проводку документа. 
 В этот момент:  
ТМЦ будут добавлены на склад.  
Будет создана бухгалтерская проводка  ДБ Inventory On Stock \ КТ Goods Received Not Invoiced  

10. Для отправки печетной формы на печать необходимо нажать (1) [Печать]\[Print] расположенную на Панели инструментов. Эта форма является документом подтвержения прихода товара для Поставщика. 
Для генерации печатной формы в электронном виде - нажать кнопку (2) [Предпросмотр]\[Preview] и затем сохранить форму как pdf файл.

<img src="/.attachments/image-40bc7b74-ed77-48cd-8651-ba649220d467.png" alt="image.png" width="100%" />
